# LUCID

**See clearly. Feel deeply. Connect truly.**

The social platform that rewards you for becoming a better human.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Set up environment
cp .env.local.example .env.local
# Edit .env.local with your Supabase credentials

# 3. Set up database
# Go to supabase.com → SQL Editor → paste contents of
# supabase/migrations/001_initial.sql → Run

# 4. Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deploy to Vercel

```bash
npx vercel
```

Or connect your GitHub repo at [vercel.com/new](https://vercel.com/new)

## Architecture

- **Frontend**: Next.js 14 + React + Tailwind CSS
- **Backend**: Next.js API Routes
- **Database**: Supabase (PostgreSQL)
- **Auth**: bcrypt + JWT + httpOnly cookies
- **Storage**: Supabase Storage (images)

## Features

- **Depth-first navigation** — no infinite scroll
- **User-created Sparks** — challenges, not content
- **Humanity Index** — five-axis measure of human growth
- **Torchbearer recognition** — community-granted, not self-earned
- **Connection DNA** — 3D helix visualization of relationships
- **Witness Circles** — small groups, deep commitment
- **Connection Threads** — 2-hour delay DMs
- **Multi-language** — 9 languages, auto-detected
- **Content moderation** — pure soul interactions only
